# Project structure

One repository: the C library and its hosts, their tests and benchmarks, the board ports, and this specification. Directories join the tree when the issue that first fills them lands; the tree below is the target, and [the checklist](18-delivery-checklist.md) records which steps have built which parts.

```text

  LICENSE                      Apache-2.0
  CMakeLists.txt               the root project: options, modules, hosts, tests, benchmarks
  CMakePresets.json            dev, asan, ubsan, msan, tsan, fuzz, release, android-arm64, armv6m, rv32imc;
                               later ios, pico, esp32c3, linux-aarch64
```

## Rules

1. **Modules are directories.** `src/<module>/` builds one static library, `pr3_<module>`, through `pr3_add_module`, which also records its layer for `check-layers.sh`. A module's public header is `include/pr3/<module>.h`; its private headers stay in its directory.
2. **Layers point down.** The order is the one in [part 02](02-architecture.md#modules); `trusted/` includes only `base`, `json` and `crypto`.
3. **No heap in `src/` except `src/platform/`.** Every portable `.c` includes `pr3/poison.h` last.
4. **Every parser has a fuzz target** in `test/fuzz/` with a corpus, before it merges.
5. **Every test has a stable name.** A test is a function `test_<behaviour>` in `test/unit/test_<module>.c`, and the [test ledger](20-test-ledger.md) lists it, so coverage can be checked by grep.
6. **Generated files say so** in their first line, with the command that regenerates them; `tools/` checks that regenerating changes nothing.
7. **Third-party code is fetched, never edited in place.** `tools/fetch-third-party.sh` checks out each entry of `third_party/manifest.txt` at its pinned commit; a needed change is a patch file under `third_party/patches/`, applied by CMake.
8. **Text the model or the user sees lives in one place per module** (`prompt_text.h`, `strings.h`), each string with a stable id.
9. **C++ stays in its box.** Only `bench/mlperf/` and third-party sources compile as C++; PR3's own sources compile as C17 ([D-22](19-decisions-and-risks.md)).
