# New task and restart: isolation regression (10 November 2026)

**New task now stays empty after restart.** Previously it cleared only the
in-memory selection, so startup could select the newest stored task and expose
its details in the next conversation. Schema v7 persists the device's selection,
including an explicitly empty conversation, separately from task lifecycle.
Navigation commits before success is reported; a new task and its selection
commit together. Task history stays available through explicit return.
